Boolean && rendering

After this you can show and hide part of a page with &&, and say why a number is the wrong condition.

Problem 3 · Interactive · 15 min · On a laptop

This one is a small React project, not a quiz. The page already runs. Three comments in src/App.jsx say what is wrong. You fix them, one at a time.

Get the code

git clone https://github.com/UW-INFO442-AUT26/442-exercises
cd 442-exercises/practice/boolean-and-rendering
npm i
npm run dev

Open the address it prints, usually http://localhost:5173. Change one thing, save the file, and look at the page. It updates by itself.

What to fix

  1. A counter that should be a boolean. A boolean is a value that is either true or false. The counter only goes up, so the button never comes back down.
  2. A card that always shows. Nothing is guarding it yet. You will put a condition in front of it with &&.
  3. A 0 that shows up when the condition is a number. Look at the page to spot it.

Done when

  • The button shows the card. The same button hides it again.
  • Nothing is left behind when the card is hidden.
  • npm run lint has nothing to say.
